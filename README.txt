DIGITAL BUSINESS CARD - GITHUB PAGES
====================================
1. Create a new PUBLIC repository on GitHub with a neutral name, e.g. "contact-card".
2. Upload everything in this folder to the TOP LEVEL of the repo (not inside a sub-folder):
   index.html, card.jpg, angela-reed.vcf, manifest.webmanifest, sw.js, the five .png icons, .nojekyll
3. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
4. After a minute or two the live link shows on that Pages screen.

"View My Listings" link: open index.html, find "Settings you can change" near the bottom,
and change LISTINGS_URL. CARD_URL stays blank; the Share QR uses the card's own address.
